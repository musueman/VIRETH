## 이미지 확인

## 적용 준비

1. 별도 시작 로어는 사용하지 않는다. 온라인 확인 당시 시작_이설소환 항목은 없었다. 소환 경위·담당관 역할·초기값은 시작상황에만 둔다.
2. 유일한 모드 규칙 로어: 생활 적응, 서로 가르치기, 이설의 자발적 제안, 경험의 후속 활용. 추가 점수 없음.
3. 시작상황 본문과 초기값: 소환과 임명 설명은 끝났으며, 이설과 왕궁을 나와 동행하는 첫 장면에서 시작한다. 공유 상태 형식은 시스템에 그대로 둔다.
4. 위키 수정은 기존 준비본의 역할·고향·등장·이미지코드·불안 항목을 반영. SP01–SP30을 55–84로 교체.
5. 82번은 최종 승인한 긴 환도 이미지임을 시각 확인. 83번도 첨부 승인본과 일치하며, 기존 설명 ‘무거운공격흘리기’는 그림과 달라 준비본에서 ‘낮은자세쌍검’으로 바로잡았다. 이미지 자체는 교체하지 않는다.
