# 비레스 소개페이지 업데이트 내역 증분 갱신 설계

## 목표

루나톡 캐릭터 `70170` 소개페이지의 `업데이트 내역`을 프로젝트 전체의 완료 증거에 맞춰 갱신한다. 기존 공개 기록은 삭제하지 않고, 검증과 공개가 끝난 주요 변경만 최신순으로 추가하거나 구체화한다.

## 완료 판정 기준

공개 업데이트로 기록하려면 다음 조건을 모두 만족해야 한다.

1. 활성 정본 폴더 또는 Git 저장소에 결과물이 존재한다.
2. 관련 계약 테스트, 검수 보고서 또는 산출물 개수 검증을 통과했다.
3. 루나톡·Vireth Worker·이야기 서고에 실제 반영됐거나, 최종 검수 보고서에서 완료된 정본 산출물로 판정됐다.

계획서만 존재하는 작업, `후보` 또는 `검수 전`으로 표시된 작업, 미커밋 변경, 실투입·배포 증거가 없는 작업은 기록하지 않는다.

## 정보 구조

- 기존 화면 순서 `사고·회복 공지 → 업데이트 내역 → 소개 → 시작 선택`을 유지한다.
- 기존 접이식 `details`와 제목 `업데이트 내역`을 유지한다.
- 기존 7개 날짜는 삭제하거나 합치지 않는다.
- `2026-08-01`, `2026-07-31` 항목을 추가해 총 9개 기록으로 구성한다.
- 각 항목은 `time[datetime]`, 굵은 제목, 1개 설명 문단으로 구성한다.
- 최신 날짜가 먼저 오도록 내림차순으로 표시한다.
- 내부 커밋명, 버전 번호, 파일명, 관리 용어는 공개 문구에 노출하지 않는다.

## 확정 공개 기록

### 2026-08-02 - 소개페이지와 이야기 서고 연결

소개 화면을 비레스의 풍경과 렌·듀란 안내 이미지 중심으로 개편했다. 8개 시작 장면에서 각 상황과 이어지는 기록으로 바로 이동하고, 이야기 서고 안에서도 다른 시작 흐름과 여행 안내로 이어갈 수 있게 했다.

### 2026-08-01 - 비레스 5083 이야기 서고 공개

8개 시작 흐름과 연결된 기록 14편을 공개했다. 삽화 30장과 글마다 별도로 정리한 초심자 참고 설명 14세트를 함께 제공해 낯선 시간, 화폐, 행정과 생활 맥락을 읽기 쉽게 했다.

### 2026-07-31 - 세계관 정본과 지도 기준 정리

비레스의 역사, 현재 갈등, 생산, 생계와 물류 정보를 하나의 최신 기준으로 정리했다. 20개 권역과 166개 장소를 기준으로 문장, 좌표, 장소 표식과 출판·웹용 지도를 다시 맞췄다.

### 2026-07-29 - 루나톡 대화와 인물 운용 정리

대화카드 배경, 인물 표식, 감정 이미지 호출이 현재 장소와 인물 설정을 안정적으로 따르도록 정리했다. 고정 인물과 즉석 인물의 등장 범위를 나누고 역할별 설명을 다듬었다.

### 2026-07-27 - 인물 감정 이미지 확장

주요 인물 100명이 대화 장면의 감정과 분위기에 맞게 등장하도록 인물별 8가지, 총 800장의 감정 이미지를 연결했다.

### 2026-07-15 - 새로운 시작 장면과 인물 표현 추가

자유 여행자와 용병 계약 시작 장면을 추가했다. 장소 식별 기준과 경비, 상인, 민간인, 학자 등 역할별 즉석 인물 이미지를 연결했다.

### 2026-07-14 - 장소·대화카드 표현 개선

현재 지역과 장소를 한눈에 확인할 수 있는 장소 카드를 추가했다. 모바일에서도 대화카드의 인물 정보와 소속 표식이 읽히도록 조정했다.

### 2026-07-12 - 비레스 5083 시작 안내 공개

정해진 선택지 없이 주변 사람과 장소를 따라 움직이는 기본 시작 방식을 소개했다. 기본 시작과 역할형 시작을 고를 수 있는 안내를 마련했다.

### 2026-07-10 - 지도와 도시 장면 연결

도시·장소 배경을 대화에 불러오는 장면 시스템에 지역 지도를 연결했다. 현재 장소 표시를 더해 이동 흐름을 확인할 수 있게 했다.

## 제외 항목

- 루나톡 통합 DB v11 정본 동기화 후보
- 전체 재색인 계획과 생성 후보 데이터
- 2026년 8월 3일 시작 역할 첫 장면 보강
- 미커밋 상태의 지도, 대화 배경, Worker 변경
- 검수 또는 실투입 여부가 확인되지 않은 장기 확장안

이 항목들은 완료·검증·공개 조건을 모두 만족한 뒤 별도 날짜의 업데이트로 추가한다.

  `tests/test_vireth_intro_page.py`
- 기존 사고·회복 공지, 소개 문구, 8개 시작 카드, 호출어, 이미지 URL과 링크는 수정하지 않는다.
- 루나톡 편집기에는 검증된 전체 HTML을 다시 넣고 실제 미리보기에서만 확인한다. 저장은 별도 승인 전에는 누르지 않는다.

## 검증

- 업데이트 날짜가 정확히 9개이며 다음 순서여야 한다.
  `2026-08-02`, `2026-08-01`, `2026-07-31`, `2026-07-29`, `2026-07-27`, `2026-07-15`, `2026-07-14`, `2026-07-12`, `2026-07-10`
- 각 `data-update-date`와 `time[datetime]` 값이 일치해야 한다.
- 확정 제목과 핵심 수치 `8개`, `14편`, `30장`, `14세트`, `20개 권역`, `166개 장소`, `100명`, `800장`이 누락되면 검증기가 실패해야 한다.
- 기존 7개 날짜가 모두 남아 있어야 한다.
- `후보`, `검수 전`, `재색인`, `8월 3일` 진행 항목을 완료된 공개 업데이트처럼 노출하지 않는다.
- 소개페이지 계약 테스트와 원격 URL 검증을 모두 통과해야 한다.
- 루나톡 실제 미리보기에서 데스크톱과 모바일 폭을 확인한다.
- 업데이트 내역을 펼쳤을 때 가로 넘침, 잘림, 겹침, 깨진 문자, 빈 이미지가 없어야 한다.
