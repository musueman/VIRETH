## 추천 방향 — 여행의 목차

기존의 흰색 헤더와 이어지는 따뜻한 흰색 바탕, 짙은 남색 제목, 가는 금색 구분선으로 구성한다. 첫 화면의 화려한 그림과 경쟁하기보다는, 책의 목차처럼 목적지를 빠르게 찾는 메뉴로 만든다. 작은 버튼·링크는 현재 본문의 고딕체를 유지한다.

큰 장식 이미지 대신 기존 VIRETH 로고를 아주 옅은 단색 워터마크로 한쪽에 둔다. 기존 승인 배경 한 장을 보조 카드에 쓸 수 있으나 메뉴 글자 뒤에는 깔지 않는다. 새 이미지 제작은 필수 아님.

루나톡 목적지는 기존 `https://lunatalk.chat/character/detail/70170`을 유지한다. 개인 채팅방으로 즉시 이동한다고 표현하지 않고, 새 탭·로그인 또는 인증 가능성을 알려준다.

## 화면 크기별 배치

- 모바일: 화면 높이에 맞는 전체 메뉴 패널. 상단 로고/닫기를 고정하고 본문만 스크롤. 안내 6개는 현재 안내 페이지에서만 기본 펼침, 그 외에는 접힘. 나머지 주요 목적지는 바로 노출한다.
- 태블릿: 동일한 패널 안에 2열 묶음. 줄바꿈을 허용하되 서체를 줄여 억지로 맞추지 않는다.
- 데스크톱: 기존 상단 직접 링크와 햄버거를 함께 노출한다. 넓은 화면은 3열, 태블릿은 2열 목차 패널을 사용한다.
- 후속 사용자 요청에 따라 메뉴는 푸터보다 낮은 z-index 14, 푸터/캐릭터는 15, 헤더는 20으로 배치한다. 푸터는 시각적으로 앞에 남되 배경 조작은 잠근다. 메뉴 내부 스크롤 영역은 실제 푸터 높이를 제외하며, 닫으면 기존 스크롤 위치를 유지한다.

## 동작과 검수 기준

- 480ms 패널 펼침과 500ms 콘텐츠 등장, 묶음별 40~260ms의 짧은 시차. 닫힘은 360ms. 항목별 긴 시차나 지속적인 글자 흔들림은 쓰지 않는다.
- 메뉴 버튼에 펼침 상태, 패널에 대화상자 이름 제공. 포커스 이동/가두기, Escape 닫기, 닫은 뒤 원래 버튼으로 포커스 복귀.
- 배경 스크롤 잠금, 메뉴 안 세로 스크롤 허용, 브라우저 뒤로 가기·경로 이동 시 닫힘 처리.
- 최소 44px 조작 높이, 현재 페이지 표시, 고대비 포커스 표시, reduced-motion 지원.
- 390×844 / 412×915 / 768×1024 / 1920×1080에서 메뉴 하단까지 접근 가능하고 가로 넘침이 없어야 한다. 추가로 가로 방향의 낮은 화면과 실제 iOS Safari를 확인한다.
