# 비레스 5083 루나톡 캐릭터 소개페이지 디자인

## 1. 목적

루나톡 캐릭터 `idx=70170`의 소개페이지를 비레스 5083의 실제 대화 진입 화면으로 다시 구성한다.

사용자는 소개를 읽는 즉시 다음 세 가지를 이해할 수 있어야 한다.

1. 비레스는 정답 선택지보다 장면 속 사람, 장소, 물건과 대화하며 움직이는 여행형 시뮬레이션이다.
2. 출신과 목표를 완성하지 않아도 8개 시작 장면 중 하나에서 바로 시작할 수 있다.
3. 더 읽고 싶다면 이야기 서고에서 자신의 시작과 이어지는 기록을 찾을 수 있다.

별도 마케팅 랜딩 페이지를 만들지 않는다. 루나톡의 기본 대화 시작 기능을 밀어내지 않고, 소개 본문 안에서 장면 선택과 보조 자료 탐색을 돕는다.

## 3. 현재 화면 감사

### 잘 작동하는 부분

- 8개 장면이 모두 서로 다른 이미지와 함께 표시된다.
- 카드의 국소 어두운 오버레이 덕분에 밝은 장면에서도 제목이 읽힌다.
- 화이트모드에서도 바깥 페이지 색상과 무관하게 본문 배경과 글자색이 유지된다.
- 호출어와 역할형 시작 방법이 소개 본문 안에 정리되어 있다.

### 개선할 부분

- 모바일 첫 화면이 사고 공지와 변경 내역만으로 끝나 비레스와 시작 선택이 늦게 등장한다.
- 공지, 변경 내역, 링크, 시작 선택, 호출어가 모두 테두리와 배경을 가진 독립 박스여서 페이지 전체가 상자의 연속처럼 보인다.
- 비레스의 실제 인물 신호가 없어 풍경 자료 모음처럼 느껴진다.
- `세계 안내`, `시작상황 문서`, `프로젝트 반영 내역` 같은 관리 용어가 행동보다 문서 구조를 먼저 드러낸다.
- 모바일에서 장면 카드 8개가 세로로 이어져 호출어까지 도달하는 거리가 지나치게 길다.
- 이야기 서고가 생겼지만 기존 시작상황 문서 링크와 문구가 남아 있다.
- 카드와 명령어 설명이 반복적으로 박스 안에 들어가 시각적 위계가 평평하다.

## 4. 디자인 원칙

### 4.1 장면을 먼저 보여 준다

사고 안내는 최상단에 남기되 높이를 줄인다. 그 다음 화면에는 바로 `비레스 5083`, 실제 풍경, 렌과 듀란, 시작 장면 일부가 보이게 한다.

### 4.2 박스는 기능이 있을 때만 사용한다

프레임을 허용하는 요소는 다음뿐이다.

- 중요한 사고 안내
- 클릭하거나 펼칠 수 있는 시작 장면 카드
- 외부 페이지로 이동하는 실제 버튼
- 접고 펼치는 보조 정보 조작부

소개 문장, 섹션 제목, 간단한 사용 흐름은 별도 카드에 넣지 않는다. 배경 밴드, 구분선, 충분한 여백으로 영역을 구분한다.

카드 안에 다른 카드를 넣지 않는다. 전체 섹션을 떠 있는 카드처럼 만들지 않는다.

### 4.3 실제 이미지와 글자를 함께 살린다

- 장면 카드마다 기존의 서로 다른 실제 이미지를 유지한다.
- 전체 이미지를 밝게 덮는 막을 사용하지 않는다.
- 텍스트가 놓이는 왼쪽 또는 아래쪽에만 국소 어두운 그라데이션을 둔다.
- 인물과 주요 건축물이 텍스트에 가려지면 이미지의 초점 위치를 카드별로 조정한다.
- 이미지 안의 읽을 수 있는 글자나 웹툰 말풍선을 장식 배경으로 사용하지 않는다.

### 4.4 렌과 듀란은 안내용 시각 앵커다

렌과 듀란은 첫 소개 밴드에서 비레스를 먼저 걷고 있는 두 여행자로 표시한다.

- 문서 저자, 기록자, 모든 시작 장면의 당사자로 표현하지 않는다.
- 두 인물 옆에 긴 설명 카드를 붙이지 않는다.
- 이름과 짧은 문장만 사용한다.
- 모바일에서는 인물이 제목이나 버튼을 가리지 않도록 한 명씩 부분 크롭하거나 풍경 뒤쪽으로 낮춘다.

### 4.5 사용자 행동을 말한다

딱딱한 명칭은 다음처럼 바꾼다.

| 기존 표현 | 새 표현 |
|---|---|
| 세계 안내와 시작상황 문서 | 비레스를 더 둘러보세요 |
| 비레스 세계 안내 보러가기 | 비레스를 먼저 둘러보기 |
| 비레스 시작상황별 문서 보러가기 | 내 시작과 이어지는 이야기 읽기 |
| 최근 비레스 프로젝트 반영 내역 | 최근 달라진 점 |
| 대화 중 사용할 수 있는 호출어 | 막혔을 때 이렇게 불러보세요 |
| 역할 시작·해제 호출어 보기 | 다른 역할로 시작하는 방법 |

`Arcadia`와 `아르카디아`는 공개 제목, 본문, 이미지 대체 텍스트, 생성 결과에 표시하지 않는다.

## 5. 최종 정보 구조

### 5.1 최상단 중요 공지

- 한 줄 키커: `업데이트 일정 안내`

- 금색 테두리와 진한 갈색 배경으로 중요도를 유지한다.

### 5.2 비레스 소개 밴드

- 브랜드 키커: `VIRETH 5083`
- H1: `비레스 5083`
- 핵심 문장:
  `정해진 답을 고르기보다, 눈앞의 사람과 장소를 따라 직접 움직이는 판타지 여행입니다.`
- 보조 문장:
  `출신과 목표를 다 정하지 않아도 괜찮습니다. 마음에 드는 첫 장면을 골라 말을 걸어보세요.`
- 기존 비레스 도시 풍경을 가로형 배경으로 사용한다.
- 렌과 듀란을 좌우 또는 한쪽 가장자리의 인물 앵커로 사용한다.
- 인물 표기:
  `비레스를 먼저 걷고 있는 여행자, 렌과 듀란`

이 밴드는 화면을 독점하는 거대한 히어로가 아니다. 데스크톱 높이는 약 360px 이하, 모바일은 약 420px 이하로 제한해 다음 시작 장면 일부가 첫 화면에 보이게 한다.

### 5.3 주요 이동 버튼

소개 밴드 안이나 바로 아래에 두 개의 실제 링크를 둔다.

1. `비레스를 먼저 둘러보기`
2. `내 시작과 이어지는 이야기 읽기`

두 번째 버튼은 이야기 서고 프로덕션 주소로 연결한다.

버튼에는 Lucide 계열의 실제 아이콘 자산을 사용한다.

- 둘러보기: `compass`
- 이야기 읽기: `book-open`
- 외부 이동: `external-link`

아이콘만 있는 조작부는 만들지 않는다. 아이콘 이미지에는 빈 대체 텍스트를 사용하고, 링크 자체의 문구와 `title`이 의미를 전달한다.

### 5.4 시작 장면 선택

- 제목: `어디에서 시작할까요?`
- 설명:
  `처음 정한 길을 끝까지 따를 필요는 없습니다. 지금 끌리는 장면에서 시작해 보세요.`
- 8개 장면과 기존 순서를 모두 유지한다.
- 카드마다 장면 번호, 시작 유형, 제목, 한 줄 설명을 표시한다.
- 장면 제목과 설명은 현재 확정 문구를 유지하되 관리 용어만 다듬는다.

데스크톱:

- 2열 그리드
- 카드 비율 약 `16:7`
- 같은 행의 높이는 일정하게 유지
- 카드 전체가 펼침 조작부

모바일:

- 한 화면에 다음 카드 일부가 보이는 가로 스크롤
- CSS `scroll-snap` 적용
- 카드 폭은 뷰포트의 약 82~88%
- 8개 카드가 모두 키보드와 터치로 접근 가능
- 스크롤바를 완전히 숨기지 않고 얇은 진행 신호 또는 `1 / 8` 안내를 제공

카드를 펼치면 현재 장면 설명과 시작 입력 예시만 보여 준다. 긴 웹툰과 이야기 원문은 소개페이지에 다시 넣지 않고 이야기 서고로 연결한다.

### 5.5 대화 시작 흐름

별도 카드 없이 한 줄 또는 세 칸의 단순 흐름으로 표현한다.

1. `장면을 고릅니다`
2. `눈앞의 사람에게 말을 겁니다`
3. `장소와 기록을 따라 움직입니다`

데스크톱은 가로, 모바일은 세로로 배열한다. 숫자나 연결선은 장식이 아니라 읽기 순서를 전달하는 수준으로만 사용한다.

### 5.6 호출어

## 6. 시각 체계

### 색상

- 전체 배경: 거의 검정에 가까운 중성색
- 본문: 따뜻한 백색
- 강조: 금색
- 보조 강조: 청록
- 경고: 갈색과 금색

페이지를 남색 계열만으로 채우지 않는다. 풍경 이미지의 녹색, 갈색, 청록, 황금색이 보이도록 중성 배경을 사용한다.

모든 핵심 색은 인라인 스타일에서 명시해 루나톡의 화이트모드와 다크모드 양쪽에서 동일한 대비를 유지한다.

### 테두리와 모서리

- 외곽 래퍼: 최대 8px
- 중요 공지: 6px
- 장면 카드: 6px
- 버튼: 6px
- 일반 섹션: 테두리와 둥근 배경 없음

### 글자

- 본문 최소 15px
- 모바일 본문 최소 16px
- 줄 높이 1.65 이상
- 음수 자간 사용 금지
- 본문 굵기 500 이상
- 이미지 위 제목은 텍스트 그림자와 국소 오버레이를 함께 사용

## 7. 구현 제약

- 루나톡 소개 편집기에 붙여 넣을 수 있는 단일 HTML 조각을 유지한다.
- 전역 CSS와 외부 자바스크립트에 의존하지 않는다.
- 루나톡이 `<style>` 태그를 제거한 뒤 CSS 내용을 본문에 노출하므로 `<style>`과 `@media` 블록을 사용하지 않는다.
- 핵심 레이아웃과 색상은 각 요소의 인라인 `style` 속성으로 완결한다.
- 반응형 배치는 `flex-wrap`, `auto-fit`, `min()`, `max()`, `clamp()`처럼 인라인에서 동작하는 값으로 구성한다.
- 아이콘은 직접 그리지 않고 검증된 Lucide 정적 자산을 사용한다.
- 외부 링크에는 `target="_blank"`와 `rel="noopener noreferrer"`를 사용한다.
- 이미지는 `loading="lazy"`를 기본으로 하되 첫 소개 배경과 첫 인물 이미지는 지연하지 않는다.
- 원본 8개 시작 장면의 역할, 설명, 시작 명령 의미를 바꾸지 않는다.
