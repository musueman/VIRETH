# 비레스 소개페이지 업데이트 내역 설계

## 목표

소개페이지 하단의 `최근 달라진 점`을 `업데이트 내역`으로 바꾸고, 사용자가 체감할 굵직한 변경을 최신순 날짜별 기록으로 제공한다.

## 정보 구조

- 기존 접이식 `details` 조작부를 유지한다.
- 요약 제목은 `업데이트 내역`으로 고정한다.
- 내부는 최신 날짜가 먼저 오는 `ol` 타임라인으로 구성한다.
- 각 항목은 실제 `time[datetime]`, 굵은 변경 제목, 1~2문장의 쉬운 설명으로 구성한다.
- 세부 커밋명, 내부 버전 번호, 관리용 용어는 노출하지 않는다.

## 공개 업데이트 기록

1. `2026-08-02` - 소개페이지와 이야기 서고 연결
   - 소개 화면을 비레스의 풍경과 렌·듀란 안내 이미지 중심으로 개편했다.
   - 8개 시작 장면에서 각 상황과 이어지는 이야기 기록으로 바로 이동할 수 있게 했다.
2. `2026-07-29` - 루나톡 대화와 인물 운용 정리
   - 대화카드 배경, 인물 표식, 감정 이미지 호출이 현재 장소와 인물 설정을 안정적으로 따르도록 정리했다.
   - 고정 인물과 즉석 인물의 등장 범위를 나누고 역할별 설명을 다듬었다.
3. `2026-07-27` - 인물 감정 이미지 확장
   - 주요 인물들이 대화 장면의 감정과 분위기에 맞는 표정으로 등장하도록 이미지 구성을 확장했다.
4. `2026-07-15` - 새로운 시작 장면과 인물 표현 추가
   - 자유 여행자와 용병 계약 시작 장면을 추가했다.
   - 장소 식별 기준과 역할별 즉석 인물 이미지를 연결했다.
5. `2026-07-14` - 장소·대화카드 표현 개선
   - 현재 지역과 장소를 한눈에 확인할 수 있는 장소 카드를 추가했다.
   - 모바일에서도 대화카드의 인물 정보와 소속 표식이 읽히도록 조정했다.
6. `2026-07-12` - 비레스 5083 시작 안내 공개
   - 정해진 선택지 없이 주변 사람과 장소를 따라 움직이는 기본 시작 방식을 소개했다.
   - 기본 시작과 역할형 시작을 고를 수 있는 안내를 마련했다.
7. `2026-07-10` - 지도와 도시 장면 연결
   - 도시·장소 배경을 대화에 불러오는 장면 시스템에 지역 지도를 연결했다.
   - 현재 장소 표시를 더해 이동 흐름을 확인할 수 있게 했다.

## 시각 원칙

- 타임라인은 기존 짙은 배경과 밝은 본문 색을 그대로 사용해 화이트모드에서도 독립적으로 읽히게 한다.
- 중첩 카드를 만들지 않고 날짜 왼쪽의 얇은 선과 점만으로 흐름을 구분한다.
- 날짜, 제목, 설명의 위계를 분명히 하되 본문 크기와 행간은 모바일에서 줄어들지 않게 한다.
- 좁은 화면에서는 날짜와 설명이 자연스럽게 줄바꿈되며 가로 스크롤이 생기지 않아야 한다.

## 검증

- 제목 `업데이트 내역`이 한 번만 노출되고 폐기 문구 `최근 달라진 점`은 없어야 한다.
- 7개 날짜가 정확히 한 번씩 최신순으로 존재해야 한다.
- 각 항목에 `data-update-date`와 같은 값의 `time[datetime]`이 있어야 한다.
- 승인된 7개 제목과 핵심 설명이 누락되면 검증기가 실패해야 한다.
- 기존 소개페이지 계약 테스트와 외부 URL 검증이 모두 통과해야 한다.
- 데스크톱과 모바일에서 펼친 업데이트 내역을 직접 확인해 겹침, 잘림, 빈 영역을 점검한다.
